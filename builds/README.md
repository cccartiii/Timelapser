# Timelapser

A lightweight desktop application that records your screen while you draw and automatically creates smooth timelapse videos with efficient storage usage.

[Download](../../releases/latest) • [Report a Bug](../../issues) • [Request a Feature](../../issues)

</div>

---

## About

Timelapser is built for digital artists who want to share their drawing process without dealing with massive screen recordings.

Instead of keeping hours of recorded footage, Timelapser captures your progress efficiently and generates a clean timelapse when you're finished. Just start recording, draw as you normally would, stop recording, and export your timelapse.

> **Note**
>
> This project is currently in early development. The interface is still being improved as new features are added.

---

## Features

- Automatic screen recording while drawing
- Smooth timelapse generation
- Efficient storage usage
- Lightweight desktop application
- Simple and easy-to-use interface
- Works with most drawing software

---

## Installation

1. Download the latest release from the Releases page.
2. Run `Timelapser.exe`.
3. Start recording.
4. Draw as you normally would.
5. Stop recording and generate your timelapse.
